# Калории

Личный счётчик калорий для iPhone: дневник питания, БЖУ, примерные витамины, минералы и добавленный сахар (по названию и КБЖУ продукта), замеры тела (вес, шея, грудь, бицепс, талия, ягодицы, бедро), графики и **выгрузка в PDF**. Все данные хранятся только на телефоне. Без интервального голодания, рекламы и подписок.

- `app/` — приложение (Expo SDK 58, React Native, TypeScript, SQLite)
- `replica/` — разбор функций, архитектура, дизайн-токены
- `.github/workflows/ios-ipa.yml` — сборка IPA в облаке GitHub (Mac не нужен)

## Как получить IPA

1. Залейте эту папку в репозиторий на GitHub.
2. Откройте вкладку **Actions** → **Build unsigned IPA** → **Run workflow**.
3. Через ~15–25 минут в запуске появится артефакт **Kalorii-ipa** (zip с файлом `.ipa`).
   Если отправить тег `v1.0.0` (`git tag v1.0.0 && git push --tags`), IPA ещё и прикрепится к Release —
   оттуда его удобно открыть прямо на iPhone.

Для приватного репозитория минуты macOS считаются ×10 от бесплатных 2000 мин/мес (≈ 8–10 сборок в месяц).
Для публичного — бесплатно без ограничений.

## Установка через TrollStore

IPA не подписан сертификатом Apple, бинарник подписан `ldid` («fakesign»). TrollStore ставит такие приложения навсегда:
откройте `.ipa` на iPhone → «Поделиться» → TrollStore → Install. Обновление — так же, данные сохраняются.

## Разработка

```bash
cd app
npm install
npx expo start        # живой просмотр в Expo Go на iPhone (тот же Wi-Fi)
npx tsc --noEmit      # проверка типов
```

## Данные

- Встроенная база базовых продуктов (≈200 шт., ориентировочные значения на 100 г)
- Open Food Facts — поиск по названию и штрихкоду (данные под лицензией ODbL)
- Свои продукты и блюда
- Витамины и минералы — оценка по типу продукта, справочник USDA FoodData Central (`tools/make_micro_ref.py`); если на этикетке в Open Food Facts есть данные, берутся они
- Резервная копия: Профиль → Настройки → «Сохранить копию (JSON)»
