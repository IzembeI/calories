# План проверки на iPhone (версии 1.2–1.4)

Автотесты через браузер здесь невозможны: приложение нативное и собирается только в GitHub Actions.
Что проверено без устройства: типы (`tsc`), сборка iOS-бандла, расчёты на тестовых данных
(уровни, разбор недели, расход, прогноз, график калорий, начало дня, оценка нутриентов по 212 продуктам).
Ниже — то, что можно проверить только руками. Формат: шаг → что должно быть.

## F01 Запуск и обновление с 1.1
- H1 Поставить поверх старой версии → дневник, продукты и замеры на месте; экран запуска зелёный с кольцом.
- E1 В поиске «гречка сухая» → есть стакан 210 г; «булгур сухой» находится (новые продукты добавились).

## F02 Дневник
- H1 Добавить продукт плюсом из поиска → лёгкая вибрация, запись в дневнике с картинкой.
- H2 Долгое нажатие на запись → панель «Выбрано»; скопировать на завтра → запись появилась завтра, «Отменить» убирает.
- H3 «Перенести» в другой приём пищи → запись переехала, «Отменить» возвращает.
- H4 «Скопировать весь день…» → «Выбрать день…» → в выбранном дне те же записи.
- E1 Открыть календарь для выбора дня и закрыть его → ничего не скопировано, дневник на том же дне.
- E2 Настройки → «Начало дня 04:00» → в 01:30 «сегодня» остаётся вчерашним днём.

## F03 Продукты и блюда
- H1 Блюдо: 3 ингредиента, «Блюдо с посудой» 2500, «Пустая посуда» 900 → «Готового 1600 г», КБЖУ на 100 г; после сохранения блюдо из вкладки «Мои» открывается как продукт и пишется граммами.
- H2 «Запомнить посуду» → чип с названием; нажатие подставляет вес, долгое нажатие забывает.
- H3 «Вставить список текстом»: «гречка 200», «масло сливочное 15» → оба в составе.
- H4 «Скан» в составе блюда → после штрихкода возврат в блюдо, продукт добавлен.
- H5 Блюдо без веса готового → вопрос «Сколько порций», 0,5 добавляет половину.
- H6 «Гречка сухая» → карточка с подсказкой и переходом на «Гречка варёная».
- H7 Мои продукты: поиск, «Недавние», «⋯» → удалить и «Отменить»; «Объединить с дублем…».
- E1 Сканер в авиарежиме → «Нет связи с базой продуктов» → «Записать примерно»; при появлении сети в дневнике всплывает «Нашёлся продукт по штрихкоду».
- E2 Продукт из Open Food Facts с оценкой → значок Nutri-Score.

## F04 Нутриенты
- H1 «Бургер из говяжьей котлеты» со своими КБЖУ → «оценка по составу: хлеб…, говядина…», B12 не ноль.
- H2 «Яйцо куриное» → «по таблице USDA для этого продукта».
- H3 Витамины и минералы → нажать на строку → «Что дало больше всего» и «Где взять ещё».

## F05 Прогресс и цели
- H1 «Разбор недели» и «Мой росток» открываются с вкладки «Прогресс».
- H2 После 10 заполненных дней и 4 взвешиваний → карточка «Реальный расход»; «Принять» меняет норму не больше чем на 150.
- H3 Цели → «Калорийный график»: Сб, Вс +300 → в дневнике в субботу норма выше, строка «неделя: осталось…».
- H4 Пунктир прогноза на графике веса и строка «ориентировочно …».
- E1 Плато (3 недели вес стоит) → карточка; «Перерыв на 2 недели» → в дневнике «Перерыв в диете», норма равна расходу; «Закончить перерыв» возвращает норму.

## F06 Система
- H1 Долгое нажатие на иконку → 4 действия, каждое открывает свой экран.
- H2 Настройки: выключить «Вибрация» и «Росток и серия дней» → вибрации нет, карточки в дневнике нет.
- H3 Настройки: «Перекусы» → «Полдник» → новое название в дневнике и при добавлении еды.
- H4 «Тянет сорваться?» → таймер 2:00 идёт, круг дышит, плюс добавляет в перекусы.
- E1 Сохранить копию, удалить приложение, поставить заново, восстановить → всё на месте, включая блюда с весом и уровень ростка.
